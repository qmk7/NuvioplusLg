
# Nuvio Plus LG

An independent IPTV application for LG webOS.

## Planned Features
- M3U playlist support
- Xtream Codes support
- Add-ons support
- Remote-friendly interface inspired by Nuvio
- YouTube integration

## Development Status
This project is under development and is not yet a complete or installable webOS application.

## Target Platform
LG webOS TV
